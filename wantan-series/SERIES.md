# 汪探｜WanTan 系列影片：標準流程與規範

這份文件給兩個人看：
- **製作人**：第一部分「標準流程」說明你要給什麼、什麼時候給。
- **Claude**：全部都要照做，尤其是第三部分「Claude 工作說明」。

第一集《狗關節保養到底幾歲開始？》在 `dog-joint-video/`，用的是舊版程式（時間軸補丁很多），不要再拿它當範本。新影片一律從 `wantan-series/template/` 開始。

## 一、標準流程

| 步驟 | 製作人 | Claude |
|---|---|---|
| ① 開工 | 給**完整文章**和**逐字稿** | 拆幕、做每一幕的動畫，輸出一版**有音樂、音效、字幕，但還沒有旁白**的影片（時間照語速預估），發布**分鏡板** |
| ② 交代準備事項 | — | 回覆時列出：分鏡板連結；**哪幾幕適合放真實畫面**（每幕要幾秒、直拍或橫拍、拍什麼），這幾幕先留空；**錄音注意事項**（英文縮寫、專有名詞怎麼唸） |
| ③ 改分鏡 | 在分鏡板寫修改需求、改字幕，在對話說「分鏡板有新需求」 | 照著改、重新輸出、在每則需求下回覆 |
| ④ 補素材 | 錄好旁白（整支一個檔或分段都可以）；拍好真實畫面 | 對時：動畫自動跟著旁白移動；補上旁白段落的音效；把真實畫面剪進留空的幕；輸出完整影片、更新分鏡板，並列出**念的和稿子不一樣的地方** |
| ⑤ 微調、交件 | 看完整版，最後一兩輪修改 | 交件：1080p 影片、SRT 字幕、旁白／音樂／音效分軌；手機預覽 720p |

幾個原則：
- **逐字稿是基準。** 錄音要照分鏡板上的旁白念。念的和稿子不一樣時，Claude 會列出來，由你決定改稿子還是重錄。
- **只重錄某一幕時**，在對話裡說是哪一幕；Claude 會把檔案存成幕號（例如 `07.mp3`），那一幕就固定用新錄音。
- **段落結構在 ③ 結束前定案。** 之後要加、刪幕都可以（模板支援），但會連帶重排後面的時間。
- **真實畫面太大傳不上來時**，請分段傳，或先用手機壓縮。

## 二、系列風格規範（已定案，每一集都照做）

畫面風格（兩種，製作人開新影片時說要哪一種；沒說就問）
| 風格 | 代號 | 樣子 | 樣張 |
|---|---|---|---|
| **經典米色** | `classic` | 第一集起的原有風格：米色底 `#F7EFE4`、奶油色卡片、深色幕 `#231B15` | 第一集 `dog-joint-video/` |
| **清新亮色** | `fresh` | 底色三選一：米白漸層到淡藍灰（預設）、淡綠到白（`bg-mint`）、淡藍到白（`bg-sky`）；白色圖示磚、**藍色手寫標註**（大數字＋手繪箭頭）、右側**手機畫面**（藍天頂部、白色資料卡、對話輸入框） | `style-test/fresh-1.png`～`fresh-3.png` |

- 風格寫在 `script.json` 的 `style`，開新影片時用 `./new-video.sh <代號> "標題" fresh` 指定；樣式在 `template/themes/<代號>.css`，疊在 `core.css` 之後。
- 兩種風格**共用**：頻道 logo、字型、亮色黏土感圖示（`icons.js`）、黑柴插畫、字幕樣式、橘色重點字與結論，以及下面所有規範。
- 清新亮色的**藍色 `#2E6BD8` 只用在手寫標註和手機畫面**；重點字、結論、念到的卡片框還是橘色。
- 大標：第一行黑字，**第二行用橘色**（`<b class="o">`），不用灰色。
- 清新亮色的**頻道 logo 圓底是透明的**，跟著那個角落的背景色走。
- 清新亮色的**狗一律用黏土黑柴**（`assets/dogs/clay/`：sit 坐、tilt 歪頭、happy 開心、beg 站起來拜託、belly 翻肚、stand-side 側站、yawn 打哈欠、sleep 睡覺、rest 趴著、avatar 大頭貼）；經典米色用原本的手繪黑柴。
- 清新亮色的影片右上角放**章節導覽**（目前講到哪一步），讓觀眾不會迷路；每一步開頭放一張章節卡（「STEP 01」＋大標）。
- 編號：
  - 影片有講「基本觀念」時，基本觀念的編號是 **00**（章節導覽、路線圖、小標都一樣），後面的章節依序 01、02…。
  - 文章或逐字稿有念「第幾步」時，STEP 編號和念的「第幾步」一致（念「第一步」就是 STEP 01）。

敘事與轉場（兩種風格都適用）
- 一個畫面講一件事，**念到哪個重點，那個重點才出現**；重點用橘框、橘字或印章標出來，一眼看得到。
- 出現時機：元素在旁白**念到那個詞的時候**出現，不提早、也不等。
- 手機畫面、影片框這類大元素**跟著換幕一起進來**，一次滑到定位，中間不停頓。
- 同一個主題的連續幾幕用 `enter: 'none'` 接在同一個畫面上慢慢長出來（例如路線圖、表格、對照卡），換主題才換畫面。
- 轉場要有變化：章節開頭用 `iris`（圓形擴開），同一章換主題用 `push`／`wipe`／`rise`，拉近細看用 `zoom`。可用的轉場寫在 `engine.js` 開頭。

畫面
- 16:9、1920×1080、30fps。重點色橘 `#E2620E`／`#F97316`；底色依上面的風格。
- 字型：Noto Sans TC（內文、標題）、Space Mono（編號、小標）、Bricolage Grotesque（大數字）。都在 `template/assets/fonts/`。
- 左上角固定是頻道 logo＋「汪探｜WanTan」。深色幕時自動變白字。
- 卡片：白底圓角＋柔和陰影；念到的那張加**橘框**。
- 印章、便條、圖示磚**一律擺正，不歪**。例外：印章蓋在卡片、圖片或文字上面時，可以歪一點，像真的蓋上去。
- 同一排的圖示磚**一樣大、對齊**（上緣切齊、間距相同）。
- 字卡**不加「」**；每張說明卡**只留一行說明**。
- 結論、建議用**橘色大字**，補充說明用灰色小字。
- 狗的插畫一律用黑柴（`assets/dogs/`）。

固定段落
1. **片頭**：品牌動畫 `wantan-reveal.mp4`（3.9 秒，含聲音），片頭音效收尾時疊**兩聲狗吠**。背景音樂從片頭之後才開始。
2. **開場痛點頁**：大標「想○○，你是不是也有這些困擾？」＋三張困擾卡（版型在 `scenes/01-pain.js`）。
3. 主體：依內容設計。
4. **真實畫面**：直拍影片放**右邊**，左邊放說明字卡，底色米色。**不要用模糊填滿兩側**。橫拍影片鋪滿整個畫面（版型在 `scenes/03-footage.js`）。
5. **最後提醒（免責）＋片尾 logo 停格**（版型在 `scenes/04-ending.js`）。

聲音
- 旁白由製作人提供（目前用 ElevenLabs 生成），成片時加速 1.5 倍。
- 背景音樂、音效都用程式合成，沒有授權問題。旁白出現時背景音樂自動降約 6 dB。
- 每個動作都配音效：卡片浮上「啵」、滑入「咻」、換頁「大咻」、結論「叮咚」。

字幕
- 畫面最下方置中，一則最多 18 字；句號、問號後一定斷開。
- 斷句**不能只按字數切**，要看上下文：專有名詞（例如《動物傳染病防治條例》、WSAVA、AAHA）和重點句獨立成一則，不能把一個詞切成兩半（例如「每隻狗／狗」）。在 `script.json` 的 `text` 裡用 `|` 指定斷開的位置；改完用 `node build-timing.mjs` 印出字幕，逐則看過。
- 不顯示句尾標點，也不顯示「」『』。

用詞
- 畫面上的文字和旁白用詞要一致。例如旁白念「美國動物醫院協會」，畫面就不要只寫「AAHA」。
- 英文縮寫在錄音前就決定怎麼念，並寫進逐字稿。

## 三、Claude 工作說明

### 環境

- 每支影片是 `wantan-series/videos/<英文代號>/`，由 `./new-video.sh <代號> "標題"` 從 template 複製。這個指令會順便跑 `setup.sh`，安裝 gsap、語音辨識模型和字型。
- 已經存在的影片在新環境裡要先跑一次它自己的 `./setup.sh`。

**指令（在影片資料夾裡執行）**

| 指令 | 做什麼 |
|---|---|
| `./make.sh timing` | 重算時間，列出每一幕的起訖、是預估還是錄音、是否缺畫面 |
| `./make.sh stills 12 40` | 截圖 `out/still-*.png`，檢查畫面用 |
| `./make.sh align` | 對時 `narration/rec/` 的錄音，然後重算時間 |
| `./make.sh video` | 輸出 `out/video.mp4`、`out/video.srt`、`out/preview-720p.mp4`（小於 28MB）、`out/stems/*.flac`。約每分鐘影片 5 分鐘 |
| `./make.sh board "v2：說明"` | 產生分鏡板 `board/`（index.html、frames、clips、files.json） |
| `./make.sh part 0 311 1` | 只輸出其中一段（成片 0～311 秒）的手機預覽 `out/preview-720p-1.mp4`，改了前面幾幕時用 |
| `node build-storyboard.mjs out/preview-720p-1.mp4 board "v2：說明" --upto 311` | 只輸出一段時更新分鏡板：這段之前的幕換新短片，後面的幕保留上一版；發布時 `files` 只傳有變的檔，刪掉的幕傳 `null` |
| `./make.sh seg 2` | 只輸出第 2 段的手機預覽 `out/preview-720p-2.mp4`。段落寫在 `script.json` 的 `"segments": ["01","34","56"]`（每一段第一幕的幕號）；製作人說「只輸出第二段」就用這個 |
| `node build-storyboard.mjs --seg 2 board "v5：說明"` | 只更新分鏡板第 2 段的短片（用 `out/preview-720p-2.mp4`），其他段保留上一版。分鏡板依 segments 分成可收合的「第一段、第二段…」，每段標出還沒處理的需求數 |

**交件檔放哪裡**
- `out/` 不進 git。
- 交件時把 `out/video.mp4`、`out/video.srt`、`out/stems/` 複製到影片資料夾的 `final/`，再 commit。
- GitHub 單一檔案上限 100MB：`video.mp4` 超過就不進 git（`final/.gitignore` 寫上它），直接傳給製作人；要重出就跑 `./make.sh video`。
- 檔案超過 50MB 時告訴製作人，不要硬推。

### 資料怎麼放

**script.json：唯一的稿子**
- 一幕一筆：`id`、`title`、`text`（旁白，要和錄音一字不差）。
- 選填欄位：
  - `group`：分鏡板分組，寫在每組第一幕。
  - `music`：`hook`／`core`／`dark`／`step`／`light`，沒寫就沿用前一幕。
  - `pre`／`post`／`hold`：前後留白、多停的秒數。
  - `minLength`。
  - `footage: { seconds, orient: "portrait"|"landscape", shot }`。
- 旁白裡的 `|` 代表字幕強制斷開，不念、不顯示。
- 幕號用兩位數字，要插入就用 `03b`。順序以陣列為準，檔名不影響順序。

**scenes/<幕號>-<名稱>.js：每一幕的畫面**
- 用 `WT.scene('03', {...})` 寫，API 寫在 `engine.js` 開頭。
- **動畫時間一律寫「念到哪個字」**：`S.word('關鍵字')`、`S.at(k)`、`S.narrEnd`，**不要寫死秒數**。這樣錄音換了，動畫會自己跟上。
- `S.to(..., '說明')`、`S.sfx(...)` 會自動列進分鏡板，所以每個重要動作都要寫說明。
- `visuals` 用白話描述畫面元素，製作人就是看這個來提需求。
- 還沒有檔案的幕會自動顯示草稿卡（幕號、標題、旁白）。

**版面小工具 `kit.js`／`kit.css`**
- `K.scene('幕號', 章節, {...})` 取代 `WT.scene`：多了 `bg`（'mint'／'sky'）和右上角章節導覽（`K.CHAPTERS` 寫在第一個幕檔最上面）。
- 常用元件：`K.h` 大標、`K.kicker` 小標、`K.dog` 黏土黑柴、`K.tile` 圖示磚、`K.anno`＋`K.arrow` 藍色手寫標註、`K.phone` 手機畫面、`K.chk` 打勾。
- 常用動畫：`K.lines` 大標冒出、`K.pop` 彈出、`K.rise` 浮上、`K.draw` 畫箭頭、`K.ring` 橘框、`K.count` 數字跑動、`K.stamp` 蓋印章、`K.type` 打字。都會自動配音效、寫進分鏡板。
- 範例：`videos/dog-vaccine/scenes/`。

**其他**
- 這支影片自己的樣式放 `scenes.css`；系列共用的放 `core.css`、`kit.css`、`themes/`，改了要同步回 template。
- 真實畫面：
  - 原檔放 `assets/footage/source/`（不進 git）。
  - 剪接表寫在 `assets/footage/footage.json`。
  - 跑 `python3 build-footage.py`，剪好的 `<幕號>.mp4` 會進 git。
- 錄音放 `narration/rec/`，這個資料夾進 git。
  - 檔名隨意，每一幕會自動找念得最完整的檔。
  - 單幕重錄就命名為 `<幕號>.mp3`。

### 第一輪：收到文章和逐字稿

1. `./new-video.sh <代號> "標題" [classic|fresh]`（製作人指定的風格；沒指定就先問）。
2. 把逐字稿拆成幕，寫進 `script.json`。
   - 一幕大約 5–20 秒，一個畫面講一件事。
   - 固定段落（痛點、真實畫面、最後提醒）照系列規範。
   - 痛點、最後提醒如果逐字稿沒有，**先問製作人要不要加**，不要自己寫旁白。
   - 文章用來補足畫面要放的資料、數字、來源。**畫面上的資料一定要能在文章裡找到出處**。
3. 找出適合放真實畫面的段落：
   - 適合的通常是：飼主自己的經驗、示範動作、狗的日常、實際操作。
   - 這些幕設 `footage`，填好需要的秒數（＝這一幕旁白的預估長度，取整數往上加 1）、直拍或橫拍、拍什麼。
4. 每一幕寫 `scenes/` 檔，示範內容要換掉或刪掉。
5. 檢查和輸出：
   - 先用 `./make.sh stills` 逐幕檢查（照下面「輸出前檢查」）。
   - 再跑 `./make.sh video`、`./make.sh board "v1：第一版分鏡"`。
6. 第一次發布分鏡板：
   - 先載入 `artifact-capabilities` skill，用 `capabilities: {"db":{}, "downloads":{}}` 發布 `board/index.html`。
   - `files` 用 `board/files.json`，`root` 設為 `board/`。
   - 把分鏡板網址寫進 `script.json` 的 `board` 欄位，之後每一輪都更新同一個網址。
7. Commit、push，把 `out/preview-720p.mp4` 傳給製作人。
8. 回覆製作人：
   - 分鏡板連結。
   - 真實畫面清單：哪一幕、幾秒、直拍或橫拍、拍什麼。
   - 錄音注意事項。

### 每一輪：「分鏡板有新需求」

1. 讀分鏡板資料庫：
   - `requests`：status 是 `new` 的需求。
   - `subtitles`：status 是 `edited` 的字幕修改。改字幕＝改 `script.json` 的 `text`，那一幕之後要重錄。
2. 修改 → 輸出前檢查 → `./make.sh video` → `./make.sh board "vN：…"` → 發布分鏡板，發布方式同上；省略 capabilities 和 icon。
   - 如果發布被拒，說有沒看過的檔案：先用 `scope: "files"` 列一次檔案，再發布。
3. 把需求改成 `done`：
   - 用 batch 更新，每筆帶上剛讀到的 `if_version`。
   - 內容：`{status:'done', doneIn:N, reply:'改了什麼'}`。
   - 字幕修改改成 `applied`。
   - 做不到或需要製作人決定的，改成 `question` 並寫明原因。
4. Commit、push，傳 720p 預覽，用中文簡短回覆：改了什麼、要製作人確認什麼。

### 收到錄音

1. 存進 `narration/rec/`，跑 `./make.sh align`。
2. 檢查對時報告：
   - 「沒有錄音」的幕：要說明是漏錄，還是那一幕本來就沒有旁白。漏錄的幕照樣做畫面（時間照語速估、沒有聲音），分鏡板畫面說明第一行寫「（這一幕還沒有錄音）」，並列出要補錄的稿子和檔名（`<幕號>.mp3`）。
   - 「只對上 xx%」的幕：打開 `narration/work/*.recognized.txt` 比對。
   - 念錯、多念（例如多出「來」這類雜音）、少念的地方都要列給製作人。
     - 小問題可以剪掉：在 `narration/work/` 裡處理加速後的錄音，接點做 10ms 淡入淡出，處理完要再對時確認。
     - 其他的請製作人重錄那一幕。
3. 動畫會自動跟著旁白移動。輸出前用 `./make.sh stills` 抽查幾個「念到才出現」的時間點。
4. 輸出影片、更新分鏡板，同一般每一輪。

### 收到真實畫面

1. 原檔存進 `assets/footage/source/`；檔案太大時先轉成 1080p H.264。
2. 逐一看過每段素材（抽幾格截圖），再寫 `footage.json`：
   - 照旁白內容排順序，每段寫上說明。
   - 直拍放直拍的幕。橫拍素材要放進直拍框時，用 `cx` 選裁切中心。
   - 狗不清楚、晃動太大的片段不要用，並告訴製作人換哪一段。
3. 跑 `python3 build-footage.py`，再輸出影片。

### 輸出前檢查（每一輪都做）

用 `./make.sh stills` 截每一幕最後的畫面（元素都出現了），逐張看過下面幾項，有問題先修再輸出：
- **重疊**：圖片蓋到字、字蓋到線（折線、虛線、框線）、手寫標註壓到框。顏色相同的元素疊在一起也算，例如橘色重點線疊在橘字上會看不見。
- **對齊**：
  - 打勾的列不能整排推到右邊（`.chk` 預設 `margin-left:auto`，放在列的最前面時要改成 0）。
  - 標籤要放在它對應的東西（括號、兩支箭頭、兩塊圖示磚的間隔）的正中央；寬度會變的標籤用 `xPercent: -50` 置中，不要用估的。
- **方向**：針筒、箭頭、視線要指向對的地方，例如針頭要朝向狗的背，箭頭指向它要指的東西。

### 注意事項（第一集學到的）

- 段落結構要早點定：插入新段落雖然支援，但會讓後面的時間全部重排，要提醒製作人在 ③ 結束前定案。
- 畫面上的英文縮寫要和旁白一致，例如 AAHA 和「美國動物醫院協會」。

- 環境閒置會被回收：
  - 錄音、剪好的真實畫面、`script.json`、`scenes/`、`board/storyboard.json`（記錄分鏡板版本號）都要 commit。
  - 真實畫面原檔不進 git，回收後就不見了。要提醒製作人自己保留原檔。
- 背景音樂、音效、字型、語音辨識都在本機處理，不需要網路。只有 `setup.sh` 下載模型時需要。
