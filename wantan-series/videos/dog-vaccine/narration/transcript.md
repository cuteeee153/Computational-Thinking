# 狗狗疫苗要打哪些？多久打一次？台灣新手飼主一次看懂

你的狗狗打疫苗了嗎？

狗狗疫苗要打哪些？這些疫苗到底在預防什麼？多久打一次？哪些是每隻狗狗都建議打的？「八合一」跟「十合一」又差在哪裡？

別擔心！今天我們從最基本的觀念開始，先帶你認識三個基本觀念：疫苗是什麼、哪些疫苗每隻狗狗都建議打，以及疫苗和預防藥到底有什麼不同。

接著，我們會認識台灣飼主需要知道的四種疾病、台灣的狂犬病疫苗規定，再來看看「五合一」、「八合一」、「十合一」到底差在哪裡。

最後，我們會整理狗狗從小到大的施打時程，讓你知道哪些疫苗需要補打，以及多久補打一次。

**先記住一句話：台灣飼主一定要先認識四種疾病，分別是犬瘟熱、犬小病毒、犬傳染性肝炎和狂犬病。**

前三種是世界小動物獸醫協會 WSAVA 和美國動物醫院協會 AAHA 都列為核心疫苗的疾病；狂犬病則是台灣法律規定，每年都要接種的疫苗。

至於其他疫苗要不要打、多久需要補打，就要看狗狗的生活環境、感染風險，再跟獸醫一起討論。

---

## 開始之前：先搞懂三個基本觀念

### 觀念一：疫苗和抗體，到底是什麼？

疫苗的作用，是先讓狗狗的身體「認識」某種病菌，身體就會產生「抗體」。抗體可以想成身體裡的「防衛部隊」，等真正的病菌來時，就能更快對抗它。

### 觀念二：什麼是核心疫苗？什麼又是非核心疫苗？

國際獸醫組織：世界小動物獸醫協會 WSAVA，以及美國動物醫院協會，也就是 AAHA。依照疾病的風險，把狗狗的疫苗分成兩大類。[1][2]

**第一種，核心疫苗。**

這類疫苗是每隻狗狗都建議接種的，主要預防傳染力強、可能造成嚴重疾病，甚至死亡的感染。

**第二種，非核心疫苗。**

這類疫苗就要看狗狗的生活方式和感染風險，再決定需不需要打。

例如，你家狗狗是不是經常去寵物旅館、狗公園？平常會不會在戶外活動，或是常常跑到溪邊、積水的地方？

這些生活習慣，都可能影響疫苗的選擇。

它們發布的是提供獸醫參考的專業指引，不是台灣的法律規定。不過，台灣的獸醫也會參考這些指引，再依照本地的疾病風險，替狗狗安排適合的疫苗。

### 觀念三：疫苗和預防藥，其實不一樣！

這點很重要，因為動物醫院裡有些打針、吃藥的項目，其實不是疫苗，而是預防藥。

兩者最大的差別是：

- **疫苗：** 讓狗狗的身體建立免疫反應，之後遇到特定病原體時，就能更快做出防禦。
- **預防藥：** 透過藥物直接預防或清除特定寄生蟲，必須按照藥物的作用時間和獸醫建議，定期使用。像是台灣很常聽到的心絲蟲，指的就是這類長效預防針劑，不是疫苗喔！[14][15]

## 第一步：台灣飼主一定要先認識的四種疾病

知道疫苗的基本觀念後，接下來就來看看，疫苗到底在保護狗狗免於哪些疾病。

有四種疾病，是台灣飼主特別需要先認識的。

第一種是狂犬病。因為人也可能感染，而且台灣有相關法律規定，所以狗狗一定要按照規定接種狂犬病疫苗。[4]

另外三種則是犬瘟熱、犬小病毒和犬傳染性肝炎。這三種疾病的疫苗，都被 WSAVA 和 AAHA 列為核心疫苗，也就是每隻狗狗都建議接種的疫苗。[1][2]

還有一種常常被討論的疾病，叫做鉤端螺旋體。兩份國際指引對它的分類有不同的發展，等一下介紹綜合疫苗時，我們再來說明。

### 1. 狂犬病

先來說狂犬病。

**狂犬病是一種非常嚴重的病毒感染，動物一旦發病，幾乎都會死亡。**[2]

而且，它不只會感染狗狗，也會傳染給人，所以是一種人畜共通傳染病。

那台灣有狂犬病嗎？

有。

根據農業部的監測資料，從 2013 年到 2025 年，台灣確診狂犬病的動物主要是鼬獾。鼬獾是一種生活在野外、常見於山區的小型哺乳動物。

這段期間累計的確診案例超過一千例，另外也有白鼻心等野生動物，以及一隻狗狗確診。[5]

雖然目前台灣的狂犬病疫情主要發生在野生動物身上，但如果你家狗狗平常會去爬山、露營，或是住在靠近山區的地方，就有可能接觸到帶有病毒的野生動物。

所以，即使狗狗平常都待在家裡，也不能忽略狂犬病疫苗的重要性。

### 2. 犬瘟熱

第二種是犬瘟熱。

犬瘟熱是一種傳染力很強的病毒感染，而且不是只有某個器官會受到影響，它可能影響狗狗的全身。[3]

那它是怎麼傳染的呢？

主要是透過生病動物呼出的飛沫傳播。當狗狗吸入這些飛沫，就有可能受到感染。[3]

感染後會出現什麼症狀？

一開始可能會發燒、眼睛或鼻子出現分泌物，也可能拉肚子，甚至引發肺部發炎。

更需要注意的是，它還可能影響腦部和神經系統。

有些狗狗即使原本的症狀已經好轉，之後仍可能出現神經方面的問題，而且症狀有時會持續惡化。[3]

對於沒有接種疫苗的狗狗來說，犬瘟熱甚至可能致命。[2]

### 3. 犬小病毒腸炎，也就是俗稱的「小病毒」

第三種是犬小病毒腸炎，很多人會直接叫它「小病毒」。

這是一種可能致命的病毒感染，特別容易發生在幼犬，以及沒有完成疫苗接種的成犬身上。[3]

為什麼這種病這麼危險？

因為病毒會嚴重破壞狗狗的腸道。

一開始可能只是沒精神、不太吃東西，或出現發燒等症狀。

但有些狗狗在一到兩天內，就可能開始嘔吐，甚至拉出帶血的便便。[3]

還有一點要特別注意：**狗狗不一定要等到出現症狀，才有可能傳染給其他狗。**

也就是說，在你發現牠生病之前，牠就可能已經把病毒傳給其他狗狗了。[3]

所以，幼犬在疫苗保護力還沒建立完整之前，更需要注意接觸其他狗狗的風險。

### 4. 犬傳染性肝炎

第四種是犬傳染性肝炎。

這種疾病是由第一型犬腺病毒引起的。[3]

狗狗可能因為接觸到感染動物的尿液、糞便或口水，再經由口腔攝入病毒而受到感染。

而且，就算狗狗已經康復，也不代表病毒馬上就完全消失。有些康復的狗狗，尿液中仍可能帶有病毒至少六個月。[3]

感染之後，症狀可能從輕微發燒，一直到嚴重疾病甚至死亡都有可能，其中又以年紀很小的幼犬風險最高。[3]

好消息是，在疫苗接種普及的地區，這種疾病已經比較少見了。

不過，還是有零星病例，因此也不能因為比較少見，就完全忽略它。[2][3]

### 這四種疾病，有什麼共同點？

那就是：**都可能造成嚴重的健康問題，甚至危及狗狗的生命。**[2][3]

這也是為什麼，犬瘟熱、犬小病毒和犬傳染性肝炎的疫苗會被列為核心疫苗，而狂犬病在台灣則有法律規定必須接種。

最後提醒一下，如果你的狗狗，尤其是還沒完成疫苗接種的幼犬，出現剛剛提到的症狀，不要自己判斷是不是感染了哪一種疾病，請盡快帶牠去看獸醫。

## 第二步：台灣的法律規定——狂犬病疫苗每年都要打

剛剛介紹的四種疾病裡，狂犬病有一個特別之處：**在台灣，飼主有法律義務替符合規定的狗狗和貓咪接種狂犬病疫苗。**

犬瘟熱、犬小病毒和犬傳染性肝炎雖然沒有相同的強制接種規定，但國際指引仍建議每隻狗狗都應接種相關核心疫苗。[1][2]

至於狂犬病疫苗要怎麼打、多久打一次？各縣市政府會依照《動物傳染病防治條例》發布相關公告，主要規定大致相同，但細節和實施日期可能會有差異：

狗狗和貓咪滿三個月大，就要依規定每年接種一次狂犬病疫苗。打完之後要取得政府印製的「注射證明書」，以及掛在狗狗脖子上的「證明牌」。

這兩樣都要妥善保管。特別是注射證明書，記得不要隨手丟掉，以免日後需要查驗時找不到。

如果經過獸醫診斷，確認狗狗不適合接種，並取得獸醫開立的相關證明文件，就可以依規定免予施打。但如果沒有按規定接種，可處新臺幣三萬元以上、十五萬元以下的罰鍰。

不過要注意，所有縣市的實施細節並不完全相同。所以建議你也可以查一下自己居住縣市的最新公告，確認當地的規定細節喔。

## 第三步：這些疫苗到底在哪一針？一次看懂「幾合一」

知道哪些疾病需要預防之後，接下來就會遇到另一個問題：

為什麼動物醫院有時候說要打五合一，有時候又說八合一、十合一？它們到底差在哪裡？

### 綜合疫苗和單一疫苗，有什麼不同？

在台灣的動物醫院，狗狗的疫苗大致可以分成兩種。[7]

**第一種，單一疫苗。**

顧名思義，就是針對特定疾病的疫苗。

例如狂犬病疫苗，就是另外接種的單一疫苗，不包含在一般的綜合疫苗裡。[7][10][11]

**第二種，綜合疫苗。**

就是把多種疫苗組合在同一劑裡，像是五合一、七合一、八合一和十合一。

這樣就不需要每預防一種疾病，就另外打一針。

而剛剛介紹的三種核心疫苗，也就是犬瘟熱、犬小病毒和犬傳染性肝炎，都會包含在常見的這些綜合疫苗組合中。

### 那五合一、七合一、八合一、十合一差異在哪？

我們整理了台灣動物醫院的衛教資訊、寵物品牌文章和其他網路資料，常見的組合大致如下。[7][8][10][11]

| 疫苗種類 | 犬瘟熱 | 犬小病毒 | 犬傳染性肝炎 | 犬舍咳相關（第二型犬腺病毒、副流行性感冒） | 鉤端螺旋體 | 犬冠狀病毒 |
| ------- | :-: | :--: | :----: | :-------------------: | :---: | :---: |
| **五合一** | ✓ | ✓ | ✓ | ✓ | — | — |
| **七合一** | ✓ | ✓ | ✓ | ✓ | 2 種 | — |
| **八合一** | ✓ | ✓ | ✓ | ✓ | 2 種 | ✓ |
| **十合一** | ✓ | ✓ | ✓ | ✓ | 4 種 | ✓ |

有三件事你一定要知道。

**第一，不管是哪一種幾合一，三種核心疫苗都有包含在內。**

也就是犬瘟熱、犬小病毒和犬傳染性肝炎。

所以，不要只因為數字比較小，就認為疫苗一定比較不好；也不要覺得數字越大，就一定越適合自己家的狗狗。

**第二，這些組合的差別，主要在鉤端螺旋體和犬冠狀病毒等項目。**

例如，有些組合會包含不同型別的鉤端螺旋體疫苗，有些則會加入犬冠狀病毒疫苗。

不過，這只是常見組合的整理，實際內容還是要看產品。

**第三，「幾合一」不是全世界統一的規格。**

不同廠牌、不同產品的組成可能不一樣，連計算方式都有可能不同。

例如，有些資料會把第一型和第二型犬腺病毒分開計算，所以同樣是綜合疫苗，名稱和數字也可能不同。[8]

因此，最保險的方式就是：**打疫苗之前，直接問獸醫這一針包含哪些項目，並請獸醫幫你記錄在疫苗手冊上。**

不要只看「八合一」或「十合一」的名稱，就認定內容一定相同。

### 那些多出來的疫苗，又有什麼作用？

除了三種核心疫苗，綜合疫苗裡還可能包含犬舍咳相關疫苗、鉤端螺旋體疫苗，以及犬冠狀病毒疫苗。

這些疫苗要不要打，主要要看狗狗的生活方式、感染風險，以及獸醫的評估。

不過，不同國際指引對某些疫苗的建議並不完全相同，我們一個一個來看。

**第一種：犬舍咳相關疫苗。**

犬舍咳是一類會引起狗狗咳嗽的呼吸道傳染病，特別容易在狗狗密集的地方傳播，例如收容所，或其他有很多狗狗一起生活的環境。[2]

依照 WSAVA 的指引，一般家犬通常會依照風險評估，決定是否需要接種這類非核心疫苗；但對於住在收容所等高密度環境的狗狗，就可能需要更積極的疫苗保護。[1]

**第二種：鉤端螺旋體疫苗。**

鉤端螺旋體是一種細菌，老鼠和其他野生動物可能帶有這種細菌。

如果狗狗經常在戶外活動、接觸積水，或是常去寵物旅館、狗狗安親班，就需要特別留意感染風險。

而且，鉤端螺旋體也可能傳染給人，是另一種人畜共通傳染病。[2]

那到底需不需要打？

這裡有一個值得注意的差異。

AAHA 在 2022 年版的犬疫苗指引中，將鉤端螺旋體疫苗列為非核心疫苗；不過，到了 2024 年更新時，AAHA 已經把它改列為所有狗狗都建議接種的核心疫苗。[2][6]

WSAVA 的建議則是，要看當地是否存在這種疾病、當地流行的是哪些型別，以及有沒有適合的疫苗。符合相關條件的地區，才會把它列為核心疫苗。[1]

至於台灣目前應該怎麼選，這次整理的資料沒有找到足夠的台灣官方犬隻疫苗建議可以直接下結論。

因此，建議你把狗狗的生活習慣告訴獸醫，再一起討論是否需要接種。

**第三種：犬冠狀病毒疫苗。**

WSAVA 目前不建議常規施打犬冠狀病毒疫苗，主要原因是現有證據不足以顯示，這種病毒是造成成犬重要臨床疾病的主要原因。[1]

所以，如果你發現某些綜合疫苗包含犬冠狀病毒，可以詢問獸醫，是否有其他更符合自家狗狗需求的疫苗組合。

## 第四步：狗狗什麼時候要打疫苗？長大後多久打一次？

知道疫苗有哪些之後，最後就是大家最常問的問題：

狗狗從小到大，到底要打幾次？長大以後又要多久補打一次？

我們先從幼犬開始說起。

### 小狗為什麼要連續打好幾劑？

小狗剛出生的時候，會從媽媽的初乳中獲得一些抗體，幫助牠度過剛出生、免疫系統還沒成熟的階段。

但這些從媽媽身上得到的抗體，也有一個需要注意的地方：**它們可能會干擾疫苗的效果。**

而且，每隻小狗從媽媽身上得到的抗體量不一樣，抗體消失的時間也不一樣。

所以，獸醫沒辦法只靠小狗的年齡，就精準判斷哪一天接種一定有效。

這也是為什麼，幼犬需要連續接種好幾劑疫苗。

透過分次接種，可以提高在媽媽給的抗體逐漸消失後，至少有一劑疫苗能成功刺激小狗產生自身免疫保護力的機會。[1][2]

### 幼犬的疫苗時間表，通常怎麼安排？

我們整理了台灣動物醫院的衛教資料、寵物品牌文章和媒體報導，常見的安排大致如下。[7][8][9][12]

先提醒一下，這張表是把台灣常見的做法整理在一起，並不是全台統一的官方時程。實際要怎麼打，還是要由獸醫依照狗狗的年齡、健康狀況和疫苗紀錄來安排。

| 狗狗年紀 | 常見的施打安排 |
| ---------------- | ----------------------------------------------- |
| **約 2 個月大** | 接種第一劑綜合疫苗。[8][9][12] |
| **約 3 個月大** | 接種第二劑綜合疫苗。[8][9][12]；依台灣法規，也要開始接種狂犬病疫苗。[4] |
| **約 4 個月大** | 接種第三劑綜合疫苗。[8][9][12]；部分資料建議可在這個時候一起接種狂犬病疫苗。[12] |
| **完成幼犬階段的疫苗接種後** | 後續要依照獸醫安排補強。部分動物醫院的衛教資料建議，完成三劑後再帶狗狗到戶外活動。[7] |

不過，國際指引在幼犬的疫苗安排上，還有一些需要注意的細節。

台灣常見的「兩個月、三個月、四個月各打一劑」，和國際指引的安排方向大致相近，但實際施打的次數和時間，仍要看狗狗的狀況及獸醫的規劃。

另外，在幼犬還沒有完成整個疫苗接種流程之前，牠的保護力可能還不完整。

那是不是完全不能出門呢？

建議你先和獸醫討論，哪些活動可以進行、哪些高風險環境需要避免，尤其要注意狗狗是否會接觸大量其他犬隻，以及可能受到污染的環境。

### 狗狗長大以後，每年打一次，還是三年打一次？

這是很多飼主最困惑的地方。

因為你可能會聽到動物醫院說，成犬每年都要補打綜合疫苗；但另一方面，又看到國際指引說，有些疫苗三年補打一次就可以。

這兩種說法為什麼不一樣？

我們先分開來看。

**第一種，是台灣常見的施打做法。**

部分台灣動物醫院和寵物相關資料，會建議成犬每年追加一次綜合疫苗，以及每年接種狂犬病疫苗。[7][12]

**第二種，是國際指引對核心疫苗的建議。**

WSAVA 和 AAHA 指出，對於犬瘟熱、犬小病毒和犬傳染性肝炎這三種核心疫苗，如果狗狗已經完成幼犬階段的接種，以及後續必要的補強，在符合指引條件的情況下，這些核心疫苗通常不需要每年補打，而是可以每三年補強一次。[1][2]

那問題來了，為什麼台灣常見的建議和國際指引會不一樣？

其中一個原因，就是不同疫苗的保護期並不相同。

例如，鉤端螺旋體疫苗的保護力通常需要每年補強，因此國際指引會建議依照適用情況定期接種。[1][2]

而從前面那張綜合疫苗表可以看到，有些七合一、八合一或十合一疫苗會包含鉤端螺旋體疫苗。

如果狗狗需要這類疫苗的保護，而你每年都使用包含它的綜合疫苗，那麼原本可以間隔較久補強的核心疫苗，也可能跟著每年一起接種。

不過，這不代表所有七合一以上的疫苗組成都一樣，也不代表每隻狗狗都一定需要每年接種相同的組合。

**所以，你可以直接問獸醫這個問題：**

「我家狗狗需要每年補打鉤端螺旋體疫苗嗎？如果需要，那核心疫苗的部分，有沒有可能依照國際指引，改成三年補強一次？」

這樣問，就能更清楚地了解每一種疫苗的用途，也能和獸醫一起討論更符合狗狗需求的安排。

最後要特別強調，前面討論的是部分核心疫苗的國際補強建議，不能直接套用到所有疫苗上。

**而狂犬病疫苗在台灣有法律規定，符合規定的狗狗和貓咪仍須每年接種。**[4]

### 打疫苗之前和之後，還有哪些事情要注意？

最後，還有幾件事記得主動告訴獸醫。

第一，如果狗狗以前打完疫苗後，曾經出現不舒服的反應，一定要提前說明。

第二，如果狗狗目前正在生病、懷孕，或是正在服用藥物，也要讓獸醫知道，方便評估適合的接種時機。

第三，打完疫苗後，如果狗狗出現任何異常，記得盡快聯絡獸醫。如果之後還要接種其他疫苗，也要在下一次看診時，把這次的反應告訴獸醫。

### 一、台灣飼主一定要認識的四種疾病

| 疾病 | 你需要知道的事 | 疫苗在哪裡？ |
| ---------- | --------------------------- | --------------------------------------- |
| **狂犬病** | 發病後幾乎都會死亡，而且可能傳染給人。[2] | 需要另外接種狂犬病疫苗；台灣法律規定每年接種。[4] |
| **犬瘟熱** | 傳染力很強，可能影響全身，包括腦部和神經系統。[3] | 常見的綜合疫苗都有包含；WSAVA 和 AAHA 都列為核心疫苗。[1][2] |
| **犬小病毒** | 可能嚴重破壞腸道，引起嘔吐、血便，幼犬尤其危險。[3] | 常見的綜合疫苗都有包含；WSAVA 和 AAHA 都列為核心疫苗。[1][2] |
| **犬傳染性肝炎** | 症狀可能從輕微發燒到死亡都有，幼犬風險較高。[3] | 常見的綜合疫苗都有包含；WSAVA 和 AAHA 都列為核心疫苗。[1][2] |

---

如果你今天只記得幾個重點，希望你記得這三件事。

第一，犬瘟熱、犬小病毒和犬傳染性肝炎，是國際指引都列為核心疫苗的三種疾病；狂犬病則是台灣法律規定必須定期接種的疫苗。

第二，五合一、七合一、八合一和十合一，不是數字越大就一定越適合。要看實際包含哪些疫苗，再依照狗狗的生活方式和感染風險來選擇。

第三，狗狗長大後，不是所有疫苗都一定要每年補打。不同疫苗的保護期和補強間隔不一樣，記得和獸醫討論適合的安排。
